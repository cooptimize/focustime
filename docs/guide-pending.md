## Inviting teammates (IN-1, for admins)

Where: the Guide's admin part, after "People".

> **Who's set up.** Admin › People shows every Cooptimizer with yes or no for Signed in, DevOps connected, Calendar connected and, where the Teams app is set up, Teams app added. Filter by Not signed in or Set up partly.
>
> **Invite someone.** Invite on their row (or tick several and Invite several) opens a message to edit, with FocusTime's link and the first three steps. Open in Teams starts a chat with them, Open in Outlook starts an email, or Copy message. FocusTime doesn't send it: you do. The row then shows "Invited <day> by <you>", and you can invite them again any time.

Command menu: "Invite" or "Who's set up".
