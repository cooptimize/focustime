# SA-0 pictures

Every picture is from the demo ("Try the demo", fictional data), dark theme, Default text size unless it says Larger. They live on the branch `shots/sa0`, never on `main`; the pull request shows them by their pinned addresses. Phone pictures use a 390 by 844 viewport with iPhone touch, a 17 px root font as iPhone Safari gives, at 3x pixels.

Whole pages: the panel's body scrolls on its own, so each section was shot by growing the window to the body's full height; "screens" is that height over one screen (900 or 844 px). One limit: the window can't grow past 20,000 px, so `17-admin-clients-phone-admin` stops at about 23.7 of its 34.2 screens.

As someone who isn't an admin: the demo person is always an admin, so these pictures answer the page's own `admin.status` question with "no" in the browser (the server still treats the person as an admin). Only the rail and the Admin pages differ; every Settings section's body is the same, so only those differing pictures are kept (`-member`).
