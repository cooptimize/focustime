# docs/ux

Each step's notes, tables and audits, in a folder named for the step. No images live here (CI-3): a step's screenshots are on the branch `shots/<step>`, and a pull request shows them by their raw addresses pinned to that branch's commit (`docs/technical/development.md`, "Screenshots").

The images that were here until CI-3 are on the branch `shots/archive` at commit `0358cb63b62411bab115214d0446a3e2f8a22ed0`, in the same folders. To see a step's, open `https://github.com/cooptimize/focustime/tree/0358cb63b62411bab115214d0446a3e2f8a22ed0/docs/ux/<step>`; one image is `https://raw.githubusercontent.com/cooptimize/focustime/0358cb63b62411bab115214d0446a3e2f8a22ed0/docs/ux/<step>/<file>.png`. The archive leaves out `U1/screens/live/`, screenshots of real data, which are only in the history before CI-3.
