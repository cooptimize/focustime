# BT-1: every browser test file

One row per file under `e2e/` that vitest runs (the screenshot scripts in `e2e/shot-scripts/` are not run in CI). Old path, the folder by screen it moves to (D) and its new name, what it covers, how it starts, and its CI time (the median of ten runs, `before.md`).

- **Starts**: how many demo servers (or real-session servers on fakes) the file starts, and when: `file` once in beforeAll, `per describe` once per describe with its own clock, settings or a real session on fakes, `per test` inside a test.
- **Tests**: `it` blocks as written (a loop counts once). **People**: calls that sign in a fresh demo person (`freshPage`, `openApp` or a real-session sign-in), as written.
- **Changes data**: whether a test calls an action that writes or presses a button that saves (found in the code by pattern, then read where unsure). `reads` means only reads and local preferences.
- **Own clock or settings**: a start with a clock other than the harness's Monday 9:30, or environment variables.
- **Share one start**: whether the tests can run on one start. Every file but three already does; the rest start once per describe, which they need (a clock, settings or a real session of its own).
