## RS-1: Restyle: controls, icons and rows (Nov 13)

Unnumbered until merge.

| # | Status | Decision |
|---|---|---|
| - | Done | RS-1: why. The product owner looked at another product's interface as a style reference and asked to borrow its control styling, not its colors or font: "not color and exact font... but just button styling and spacing and menu/tab stuff, icons." After mockups of every screen he asked to blend the old look back in where it was better, and on tab icons said: "I kinda felt like tab iconography helped direct the flow a bit and resonate on purpose." What was wrong: every row sat in its own box, so a list of 40 rows read as 40 demands; controls came in several shapes; back, next, more, add and close were text characters in small boxes. That product is a visual reference only: FocusTime's values are its own, and no file, style or icon came from it. |
| - | Done | What didn't change: no color token changed value, no font, type size or weight step, no word except "+ Add" (and its like) and the menu group labels' capitals, no layout, order, behavior, key, address or action. Block cards on Day, Week and the phone keep the client edge, the visible border (`--border`), the selected ring, their header and their to-do rows' structure (`e2e/rs1.test.ts` measures the edge, the border and the ring in every theme and text size). Section labels stay small uppercase. |
| - | Done | New tokens, in every theme: two neutral washes (`--wash-1`, `--wash-2`: the text color over nothing), the accent wash, a wash per state color (risk, watch, ok), the quiet line (`--line`), and a switch's `--track` and `--lift`. Sizes, radii and spacing that are the same in every theme sit with the type scale: `--h-control` 32 and `--h-small` 28 (scaled with the text), `--icon` 16 (scaled), `--radius-control` (full), `--radius-input` 8, `--radius-menu` 12, `--radius-dialog` 16, `--space-section` 24, `--space-card` 16, `--space-control` 8, `--space-row` 2. Components still use tokens only (`ui/tokens.test.ts`). |
| - | Done | Wash strengths are per theme, set by contrast, never by changing a text color: Cooptimize Dark 4%, 8% and the accent at 13%; Cooptimize Light 4%, 8% and the accent at 9%; Neutral light 2%, 3% and 4% (its faint text has only 4.8:1 on the page); Neutral dark 4%, 8%, 14%. State washes are 14% everywhere. `ui/rs1-contrast.test.ts` checks muted and faint text on each wash over the page, a card and a menu, a state's color on its own wash, and a switch's track and lifted side, in all four theme blocks, at AA. |
| - | Done | The quiet line is 60% of `--border-strong` on the surface: between the surface and the control outline, about where `--border` is. Read as "between the surface and `--border`" outlined buttons were close to invisible in the dark themes (docs/open-questions.md). Block cards don't use it. |
| - | Done | Buttons. The base `button` is the outlined pill (32 high: 18 of text, 6 above and below, the line; scaled with the text), so every button that brought no shape of its own became one. `.mini` is the small pill (28). `.quiet` and `.mini.quiet` have no line and muted text. The filled ones are the names the screens already used for their one main action (`.done-btn`, `.add-work-head`, `.start-focus`, a dialog foot's `.commit`, `.ib-act.primary`, `.focus-btn.primary`, sign-in). `.mini.primary` keeps the accent's line and text (it was never filled). Weight 500 everywhere. Hover is `--wash-1`, pressed `--wash-2`, both instant. A `.link-btn` stays a link. |
| - | Done | Small buttons keep the meta size (12), not the body size: the reading that changes less, since about 450 of them sit in rows with a measured room for the title. An open question. |
| - | Done | Icon-only buttons are round with no line: 32 in headers, 28 inside cards and rows (the PS-1 target), 44 on the phone. The close button keeps its whole 44 px square as the target (UI-3) and shows a round 32 wash; a Backlog chevron keeps the row's full height as its target (BL-1) and shows a round 28. |
| - | Done | Tabs: the box around the group is gone; each tab is its icon and its word in a 32 high pill, the active one with the accent wash and full-strength text, counts as small quiet numbers. Icons: Day a calendar's days, Week four columns, Backlog an indented list, Status bars, Inbox a tray. The phone's bottom bar uses the same icons over its labels. Keys 1 to 5 and the addresses are as they were. |
| - | Done | The top bar keeps one row down to 1024 px at the Default text size: under 1320 px it sits closer (tab and button padding, gaps), and a running timer's title shortens before the bar wraps (the countdown always shows whole). Focus, Capture and Ask keep their words at every width; More is the round icon button with the name it had. |
| - | Done | Switches (Cards and Timeline, Grid and Gantt, Edit and Preview, Mine, Contributing and Everyone, the Inbox's three lists, the New form's Level, Status's My features and client report, Customers and All accounts): one track (`--track`) with the chosen side lifted (`--lift` and a small shadow). Each keeps the attribute that announces it. Each keeps the text size it had. |
| - | Done | Code's Wrap is a switch with two sides, No wrap and Wrap. Underneath it is the same checkbox with the same role and name (a switch named Wrap, on or off), so the keyboard, a screen reader and the tests find it as before; the two words are what a pointer presses, and each sets its own side. Format stays a single checkbox: it has one side. |
| - | Done | Pills: outlined means press. A status has no line: a wash, colored only for a state that needs it (late and stale watch, at risk risk, on track ok, today and now the accent). A chip you press has the quiet line when off and its wash when on. Today's pill went from a filled accent to the accent wash; a late chip lost its left stripe; a story card's state lost its ring. A size is a chip when it can be changed and a status when it only tells. |
| - | Done | Inputs and selects: 32 high and scaled, 8 radius, the quiet line, the accent line plus the focus ring when focused. The command menu's search is the dialog's own head and has no box (`.plain-input`). The capture box keeps its larger text and 10 radius. |
| - | Done | Menus: 12 radius, rows 32 high, the accent wash on the active row, the shortcut in the keyboard chip, group labels as plain muted text. An icon before every item: `ui/menu-icons.ts` (pure) takes the item's own `icon`, else reads its registry action, then its words, then its group; a chosen item shows the Done icon in that place (it was a "✓" before the label). `ui/menu.test.ts` checks that no command and no ⋯ menu item falls back to the plain dot. Dialogs have a 16 radius. |
| - | Done | The icon source is one package, lucide-react, pinned at 1.66.0 (ISC; its Feather-derived icons MIT): checked against its current docs (named imports are tree-shaken; `strokeWidth`; `nonScalingStroke`; icons are `aria-hidden` unless given a label). Chosen over drawing about 100 icons here because one drawn family at one grid and stroke is what "one icon family" needs, and drawing that many well was the bigger risk. `ui/icons.tsx` is the only importer (`ui/icons.test.ts`), by name; the built app grew by 33 KB of script (11 KB gzipped) and 27 KB of styles (4.5 KB gzipped), and no icon outside the list is in the bundle. Sizes come from the stylesheet (`--icon`), the stroke is 1.5 px at every size. |
| - | Done | FocusTime's hand-drawn icons moved to the family, so there is one source: the close X, the Backlog's and Code's chevrons, the eye on a Watching row, the calendar on a to-do's time, the Deployment mark, the assistant's microphone and the phone's bottom bar. Not part of it, on purpose: the DevOps type icons (unchanged: their shapes and colors are the project's), the brand marks and Lumen, photos, and the Roadmap's trend line (a chart). |
| - | Done | Every text character that acted as a control or a mark is its icon: ‹ › (Back, Next), ⋯ (More, with the same accessible name), + (Add), × and ✕ (Close), ▸ ▾ ⌃ (chevrons), ✓ and ✗ (Done, Close), ⋮⋮ (Grip), ↵ (Enter), ↑ ↓ (move up and down), ⚠ (a conflict), ★ (a priority), ⚑ and ◷ on the Gantt, the stepper's − and +, the Guide's + and – folds and the browser's own ▶ on a `details` (the family's chevron through a CSS mask).
