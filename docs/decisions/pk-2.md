## PK-2: Connect your Pocket (Nov 17)

Unnumbered until merge. Each person connects their own Pocket recorder in Settings with their own key; FocusTime checks it by counting their recordings from the last 7 days, only on their press, and reads nothing else.

| # | Status | Decision |

| - | Done | Where: Settings › Accounts and calendars › Pocket recorder (`ui/settings/Pocket.tsx`, setting id `pocket`), for every signed-in person. No admin step and no organization setting. |
| - | Done | STEP 0.3, Pocket's API as documented on Nov 17, 2026. Address and version: `https://public.heypocketai.com/api/v1` ([API reference](https://docs.heypocketai.com/docs/api)). The key: `Authorization: Bearer pk_…` (same page). The list call: `GET /public/recordings` with `start_date` and `end_date` (YYYY-MM-DD, read as UTC), `tag_ids`, `page` (from 1) and `limit` (20 by default, at most 100); the answer is `{ success, data, pagination: { page, limit, total, total_pages, has_more } }` ([List recordings](https://docs.heypocketai.com/docs/api/recordings/list-recordings)). Each listed recording holds its id, title, `recording_at`, duration, language, who recorded it (name and email), speakers, tags, folder, state, summaries, the transcript and a translation (same page). Keys: organization API keys with optional scopes (`recordings:read`, `recordings:write`, `templates:*`, `users:*`) and an optional expiry, made by an organization admin and shown once ([Organization API keys](https://docs.heypocketai.com/docs/api/organization/api-keys)). Not documented: where a person makes a key in the Pocket app, step by step; personal keys; how to tell a personal key from an organization one; which scope the list call needs; rate limits (a 429 is shown, no numbers or headers); the terms for use by another app (no terms page is linked from the API docs). |

(3) "A read-only key": the docs have scopes rather than a read-only switch; the guide says to choose only `recordings:read` if Pocket asks.
