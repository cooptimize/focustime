## MC-6: Calls polish after the redesign, and a chat call keeps its chat's client (Nov 18)

Unnumbered until merge.

| # | Status | Decision |
|---|---|---|
| - | Done | 1. A chat call is about its chat's client, or Internal. Its setup and its row offer only those two (`callClientChoices`, `plan/call-list.ts`), the chat's client first. The server refuses any other client when the call is kept (`meeting.call_start`, 403 `chat_other_client`, "A call started in a client's chat is about that client, or Internal. Choose one of those."), whoever asks: a reviewer, an attendee or an admin (Internal is `isInternalKey`, as everywhere). Nothing changes a kept call's client afterwards (`meeting.update` refuses calls; `SeriesPatch` has no client), so Review is the one place. Chat calls already kept under another client stay as they are, but Get it from Teams on one is refused before Teams is asked, so its words never go to the AI under that client (found by the review); the PR gives the query that counts them, never a name. A calendar call still takes any client the person follows. |
| - | Done | 2. A week row's title is never cut. When it doesn't fit beside the picker and the mark it has the whole row and goes on as many lines as it needs; the picker and the mark go under it (`calls-row long`, measured in the browser once and again when the row's width changes). On the phone a long title has the whole first line, its time and square the next, its client and mark the last. |
| - | Done | 3. On the phone no line under a call's title starts with a separator: each piece carries its "·" in front and the line is drawn 12 px to the left with that strip clipped, so a piece that starts a line shows none. |
| - | Done | 4. On the phone "N of M decided" is its own line under the Show chips, always in view; the chips scroll on their own. The stuck header is 25 px taller for it (243 against 218). |
| - | Done | 5. Group heads are the page's section label size (`--fs-1`), and a group's card has a plain border, no colored left stripe (style guide 11). |
| - | Done | 6. The counts are on the Show chips only; a group's head is its name, the same as its chip's: "New in DevOps", "Promises", "Comments" (was "Comments on stories"; a comment's line says its story). |
| - | Done | 7. With a call open beside the list its Skip all is in the call's header only; a Needs you row shows its own under the pointer or with focus when it isn't the open call. |
| - | Done | 8. In Add a call a chosen recording's time is said once, on its own line in the list; the line beside About went. |
| - | Done | 9. In Select calls the ticked rows' bar shows only once something is ticked; before that the menu item reads "Done selecting". |
| - | Done | 10. One Undo message at a time (the app's one toast; a new one replaces the last), each saying what it undoes: "Kept: <title>", "Skipped: <title>" (and "Kept: 2 promises", "Skipped: 3 proposals"). A single Skip now has one too. |
| - | Done | 11. A quote and its Transcript line show the same time: time into the call ("1:35"), the clock time on hover ("1:01 PM on the clock", in my zone). A Pocket export's lines have no time, so neither shows one. |
| - | Done | 12. Lengths use the app's words ("25m", "1h", "2h 15m", `hm` in `plan/fit.ts`): a recording's length, Add a call's Length and the part question. "checked 5 min ago" is a time ago, not a length, and stays. |
| - | Done | 13. My own promise says "your Promises" on its row and "Added to your Promises" when kept. The review says which promises are mine (`mine`: the server compares the promise's person id with mine); the page compares no name. Another person's names them ("in Lee's Promises"). |
| - | Done | 14. Open's number counts the calls outside the no-transcript fold; the fold keeps its own number ("18 calls with no transcript"). |
| - | Done | 15. Words for chat calls and Pocket recordings: Hide's message says "1 call hidden" (a hidden row may be a chat call or a recording), a hidden one gone from the window "2 you hid aren't in the last 14 days."; a chat call's mark says "Transcript in the chat". |
| - | Done | 16. After Teams refuses a chat call's transcript (its `chat_refused`), its Needs you row says "Teams refused it" in amber beside Add transcript, from the press on its row or its page. The page holds it while it is open; nothing is stored, so a read refused before isn't marked after a reload. |
| - | Done | 17. The gap form's "a" or "an" follows UC-3's rule from the type's name as written ("An mvp is at the top", "A uat task"), not its lower case; a comment above story level says "on an Epic". |
| - | Done | 18. Add a call's Day and Starts are the app's own date and time fields (`DateField`, `TimeField`), as Ask to collaborate's When. A day outside the last 14 comes back inside them (the field has no bounds of its own). |
| - | Done | 19. In Add a call a recording that already has its own row is marked "In your list", and choosing it opens that row (its review, or its setup) instead of adding a second call for it. The first one chosen is a recording with no row. |
| - | Done | 20. Dismiss: every kept call with no transcript (its one button Add transcript or Use Pocket recording) has a way out in one press: a quiet "Dismiss" on its Needs you row (on hover and focus, always on touch, 44 px on the phone) and in the call's menu. A call I added by hand is removed (`meeting.call_remove`; it exists nowhere else), for its adder only; any other kept call closes as No transcript (`meeting.call_close_none`) into Closed, and a transcript later opens it again (the pass sets it ready). It leaves Needs you at once, the tab's count drops, and one Undo message says which: "Removed: <name>" (`meeting.call_restore`) or "Closed with no transcript: <name>" (`meeting.call_reopen`, back to waiting or needs upload, only from a close of mine). The server refuses Remove for a call not added by hand and for anyone but its adder, and refuses both for a call with a transcript ("Skip all and close closes it"). A registered client call keeps its own "No transcript this week". Nothing is read, sent or written anywhere but the call's own row. This replaces any earlier "Remove this call" line. |
| - | Done | No migration, dependency or setting. The four Dismiss actions are named in the registry; they write only `meeting_series.removed_at` (a hand-added call) or the occurrence's state, as `meeting.no_transcript` does. Who sees a call, what a transcript read, a Pocket read or a DevOps write does, keys and addresses are unchanged. |
