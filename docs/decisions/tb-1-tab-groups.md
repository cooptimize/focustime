## TB-1: Tabs in three groups, Status after Calls (Nov 19)

Unnumbered until merge. Named `tb-1-tab-groups.md` because "TB-1" is already the FocusTime bot in Teams (PR #54), whose decisions sit under "TB-1" in `docs/decisions.md`. This order replaces RF-1's (Day, Week, Backlog, Status, Inbox) and MC-3's (Day, Week, Backlog, Status, Inbox, Calls, Code).

| # | Status | Decision |
|---|---|---|
| TB-1.1 | Done | The tabs' order is Day, Week, Backlog, Inbox, Calls, Status, Code, in three groups: Day, Week, Backlog; Inbox, Calls; Status, Code. A person who may not read code has the same without Code. It is written once (`TABS` in `ui/nav.ts`); the top bar, the number keys, the tooltips, the key legend (`ui/keys.ts`), the command menu's hints (`ui/menu.ts`) and the Guide's sections and shortcuts card read it from there. The registry's shortcuts for Backlog, Calls and Code (`actions/` may not import `ui/`) are checked against it by `ui/menu.test.ts`. |
| TB-1.2 | Done | Nothing else about a tab changes: no rename, and the same icon, count, address, content and who may see it. RF-1's Status dot (rule, colors, shapes, hover and screen reader words) and the Inbox's and Calls' counts are as they were. |
| TB-1.3 | Done | Two dividers: between Backlog and Inbox, and between Calls and Status. Each is a 1 px upright line about as tall as a tab's word, in the control outlines' line color (`--border-strong`, chosen in review: `--border` all but vanished on the light bar), in the middle of a 1.5em space, so the gap between groups is plainly wider than between two tabs in a group. No new color, and no group has a name on screen or in code that reaches the screen. |
| TB-1.4 | Done | A divider is decoration: `aria-hidden`, never focused, never clicked. The tabs stay one list for a screen reader, in the new order. `withDividers` puts a divider only where the group changes between two shown tabs, so never at either end of the bar or beside another; with six tabs Status stands alone after the second. |
| TB-1.5 | Done | The bar never wraps. The dividers give way first, by the bar's own room: the tab list takes the bar's free room and the dividers live in it, adding nothing to the bar's smallest width; when the bar is tight they shrink first, and once shrunk their line goes, leaving plain spacing (a container query on the divider's own width). RB-6's and MC-3's steps (the words on Focus, Capture and Ask, then the VM chip) are unchanged. Written in the style guide's top bar section. |
| TB-1.6 | Done | Number keys follow the order: 1 Day, 2 Week, 3 Backlog, 4 Inbox, 5 Calls, 6 Status, 7 Code; with six tabs 6 is Status and 7 does nothing. T (Day) and L (Inbox) are unchanged. Each tab's tooltip ends with its new key in UC-3's words ("Press 6"). |
| TB-1.7 | Done | The command menu's Views lists the seven tabs first, in the bar's order, with their keys; Calls and Code moved there from their own groups (Meetings, Code) so the list reads in order; so Enter on "code" or "git" opens Code and on "meeting" opens Calls, deliberately. No dividers or group names in the menu. |
| TB-1.8 | Done | The phone is unchanged: its bar (Day, Week, Capture, Inbox, More), More's rows and their order, and every phone screen. The Desktop version on a phone shows the new bar. |
| TB-1.9 | Done | Every address, bookmark, stored last place and Copy link works as before, and Back and Forward are unchanged. No stored data, no new setting, no migration, no new dependency; PF-1's first-download limit is unchanged. |
