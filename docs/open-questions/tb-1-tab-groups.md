Without the Dev mark (prod) they show everywhere measured. Since the lines go only where the Dev mark takes the room, is that right, or should the Dev mark itself be shorter?

A one-time "Tabs moved: Inbox is 4 (or L), Calls 5, Status 6" would help, but it needs a stored "seen" mark, which this step rules out (no stored data). Worth a small follow-up?
